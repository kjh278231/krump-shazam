최근 찾기

  • 사용자 수는 알 수 없다. 서버에 사용자 id가 없다(설치·주간 사용자 수는 웹스토어 개발자 대시보드).
  • 찾기는 S3 recordings/의 기록이다. 동의해야 쓸 수 있으므로 끝까지 마친 찾기는 모두 남는다. 개발 중 시험한 찾기도 섞여 있다.
  • 기록에는 판정이 없어 단계와 점수로 다시 계산했다(server/usage.py verdict, 서버와 같은 기준).
  • 서버 지표는 최근 일만 가져온다. 예상 비용은 Lambda 실행비(콜드 스타트 포함)와 요청 비용이고, 무료 한도와 S3 비용은 넣지 않았다.
  • 시각은 모두 한국 시간이다.
