Krump Track Finder 개인정보처리방침

시행일 2026년 10월 17일

Krump Track Finder(이하 “익스텐션”)는 브라우저 탭에서 재생 중인 음악을 듣고 크럼프 음악 라이브러리에서 같은 곡을 찾아 주는 Chrome 익스텐션입니다. 이 문서는 익스텐션이 어떤 정보를 서버로 보내고, 어떻게 쓰고 보관하는지 설명합니다. 익스텐션은 이 방침에 동의한 뒤에만 쓸 수 있습니다.

1. 서버로 보내고 저장하는 정보

사용자가 “현재 탭에서 찾기”를 누를 때만 아래 정보를 보냅니다. 그 밖에는 탭의 소리나 방문 기록을 읽지 않습니다.

정보내용
탭 오디오 녹음찾기를 누른 탭의 소리, 최대 45초
탭 제목과 주소(URL)찾기를 누른 탭의 제목과 주소
검색 결과찾은 곡, 점수, 검색 방식, 시각
결과 평가“결과가 맞나요?”에 맞음/틀림을 누른 경우 그 응답

이름, 이메일, 계정, 쿠키, 위치 같은 정보는 받지 않습니다. 저장된 녹음은 어떤 사람의 것인지 연결되지 않습니다.

2. 쓰는 목적

  • 녹음에서 곡을 찾아 결과를 보여 주기 위해
  • 곡 찾기의 정확도를 높이기 위해(검색 기준 조정, 시험용 데이터)

광고, 판매, 신용 평가 등 다른 목적으로 쓰지 않고, 다른 회사나 개인에게 팔거나 넘기지 않습니다.

3. 저장 위치와 보관 기간

  • Amazon Web Services(AWS) 서울 리전의 비공개 저장소에 암호화해 저장합니다.
  • 정확도 개선에 필요한 동안 보관하고, 필요 없어지면 지웁니다.
  • 삭제를 원하면 아래 연락처로 녹음한 날짜·시각과 영상 주소를 알려 주세요. 해당 녹음을 찾아 지웁니다.

4. 브라우저에만 저장하는 정보

동의 여부, 고른 녹음 길이, 진행 중인 찾기 상태, 라이브러리 앨범 목록은 사용자 브라우저(Chrome 저장소)에만 저장되고 서버로 보내지 않습니다.

5. 외부 서비스

  • 글꼴은 Google Fonts에서, 라이브러리 페이지의 앨범 커버는 판매처(Bandcamp 등)의 이미지 서버에서 불러옵니다. 이 서비스들은 일반 웹 요청처럼 IP 주소 등을 받을 수 있습니다.
  • “앨범 구매”나 “아티스트 보기”를 누르면 판매처 사이트가 열립니다. 그 사이트에서는 해당 사이트의 방침이 적용됩니다.

6. 권한

  • tabCapture, activeTab, offscreen: 찾기를 누른 탭의 소리를 녹음합니다(녹음하는 동안에도 소리는 계속 들립니다).
  • storage: 4번의 정보를 브라우저에 저장합니다.
  • 서버 주소 접근: 녹음을 검색 서버로 보내고 결과를 받습니다.

7. 동의 철회

팝업 아래의 “동의 철회”를 누르면 철회되고, 다시 동의하기 전까지 찾기를 쓸 수 없습니다. 이미 저장된 녹음의 삭제는 3번의 방법으로 요청해 주세요.
